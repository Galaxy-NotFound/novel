# 小说架构本

离线的小说结构整理工具（PWA），可在安卓手机、平板、电脑上用。不调用 AI。

## 文件
- `index.html` 入口
- `style.css` 样式（窄于 760px 时切换成手机布局）
- `app.js` 全部逻辑：数据 / 路由 / 各页面 / 事件
- `sw.js` 离线缓存（**改了任何文件后把 CACHE 版本号 +1**，设备才会更新）
- `manifest.json`、`icon.svg` 安装到主屏幕用

## 电脑上预览
双击 `index.html` 即可（file:// 下不启用离线缓存）。

## 装到安卓
需 HTTPS 网址：推到 GitHub 仓库 → Settings → Pages 开启 → 手机 Chrome 打开网址 → 菜单「添加到主屏幕/安装应用」。之后离线可用。

## 数据
存在各设备浏览器的 IndexedDB 中，设备之间不自动同步。书房页「全部备份」导出 JSON，另一台设备「导入备份」即可迁移。
清除浏览器数据会丢失作品，请定期备份。
